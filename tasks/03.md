# Examples
The purpose of this is to create some simple examples that perform the various
ANP calculations and print the inputs, and intermediate values and results to screen.

# Starting examples

* Tree134: A simple tree hiearchy with one goal, 3 criteria under it and an alternatives cluster under each criterion.
* Network23: A fully connected ANP network with 2 clusters.  A critieria cluster with 2 nodes and an alternatives cluster with 3 nodes.
* HamburgerStd: The standard hamburger choice model from ANP theory (that has wendys, Burger King, and MacDonalds as alterantives)
* Find a stand network with subnetworks from the superdecisions.com website, pyanp.org or other locations.
