# Implement ANP classes

## Definitions
* An ANPClass has:
  * clusters: each cluster has node in it, a name and description.  Also the clusters this cluster connects to and a pairwise comparison matrix for those connected clusters with respect to this cluster.
    * Nodes: each node has a name and description and nodes it connects to.
      * For each cluster that the node connects to (i.e. at least one node->node connection between that node and the other nodes parent cluster) there is a pairwise comparison matrix for the nodes in that destination cluster that this node connects to.
  * The cluster matrix of weights of the other clusters with respect to each cluster (these are the columns)
  * The unscaled supermatrix, derived from the pairwise comparison of the nodes.
  * The scaled supermatrix, derived from the unscaled supermatrix and the cluster
  * The limit matrix, calculated using the formulas and options from pyanp.org implementation.
  * A single designated "Alternatives" cluster which specifies the alternatives for this network (the scores we care about in the end).

# Subnetworks
* An ANPClass can have 0 or more subnetworks
* A subnetwork is uniquely attached to a single node in the network
* If an ANPClass has a subnetwork, the Alternatives are found by going through all subnetworks and getting the names of all alternatives in the subnetworks and synthesizing their scores to this level.  This can be done recursively (a subnetwork may have subnetworks of its own).
